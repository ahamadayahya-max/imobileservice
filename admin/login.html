🔑 Choisir un nouveau mot de passe
  1. Connectez-vous sur vercel.com.
  2. Ouvrez le projet imobileservice → Settings → Environment Variables.
  3. Sur la ligne ADMIN_PASSWORD : ⋯ → Edit, tapez un nouveau mot de passe, puis Save.
  4. Acceptez Redeploy (ou Deployments → ⋯ → Redeploy), attendez 1 minute.
  5. Revenez ici et connectez-vous avec ims.tlse@gmail.com et le nouveau mot de passe.
Pour votre sécurité, le mot de passe n'est enregistré nulle part sur le site : seul l'accès à votre compte Vercel permet de le changer.
